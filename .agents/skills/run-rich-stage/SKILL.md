---
name: run-rich-stage
description: Выполнить и подготовить к ручной проверке один этап Run Rich 3D из Docs/PLAN.md. Использовать при реализации или доработке этапа, не для автоматического прохождения всего плана.
---

1. Прочитать AGENTS.md, текущий этап Docs/PLAN.md и относящиеся к нему наблюдения Docs/REFERENCE.md.
2. Проверить текущие изменения и результат предыдущей ручной проверки. Выбрать только согласованный этап.
3. Реализовать его на имеющихся ассетах. Неизвестные параметры референса назвать гипотезами, вынести в настройки.
4. Проверить компиляцию и соответствующие риски. Для движения и внешнего вида сравнить одинаковые участки видео и Game View; отсутствие touch-проверки обозначить явно.
5. Дать пользователю короткую инструкцию: какую сцену открыть, что сделать, что должно произойти. Перечислить ограничения.
6. Остановиться на ручной проверке, как запросил пользователь. После положительного ответа создать коммит по AGENTS.md и обновить статус этапа. Новый этап начинать по запросу пользователя.
