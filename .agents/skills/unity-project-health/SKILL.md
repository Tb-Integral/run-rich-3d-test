---
name: unity-project-health
description: Найти и проверить ошибки импорта, компиляции, материалов, ссылок и Level Manager в этом Unity-проекте. Использовать для диагностики состояния проекта и проверки после исправлений.
---

1. Прочитать AGENTS.md и Docs/PROJECT_HEALTH.md. Сверить ProjectVersion, manifest, открытый проект и источник логов.
2. Отделить ошибки игрового кода от старых сообщений импорта, сети и лицензирования. Не считать каждое слово error текущей ошибкой Console.
3. Проверить реальные ссылки материалов, шейдеры, компоненты сцен и наличие анимаций внутри FBX; отсутствие .anim само по себе не доказывает отсутствие клипов.
4. Исправить подтверждённую причину минимальным изменением. Для выданного Level Manager сохранить совместимые сериализованные поля и GUID.
5. Использовать RunRich.Editor.ProjectValidation.Run либо меню Tools/Run Rich/Validate Project. Для batch-проверки занятого проекта использовать отдельную копию Assets, Packages, ProjectSettings; не запускать второй Editor на том же каталоге.
6. Выполнить относящиеся к изменению тесты и при необходимости сборку. Обновить Docs/PROJECT_HEALTH.md: доказательства, исправления, выполненные проверки, оставшиеся проблемы. Не объявлять визуальную проверку выполненной по логам.
