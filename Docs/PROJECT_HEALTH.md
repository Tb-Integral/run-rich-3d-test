# Состояние проекта — 16.09.2026

## Исходное состояние
Unity 6000.3.22f1; URP 17.3.0; Input System 1.20.0; Test Framework 1.6.0. Единственная сцена — SampleScene. Git ещё не был инициализирован. Сериализация Force Text уже включена.
В Assets 3119 файлов вместе с .meta, около 217 МБ: 6 FBX, 7 shader, 74 mat, 225 PNG, 23 OGG, 4 C#; нет отдельных prefab, anim, controller. Исходная папка задания содержит такой же набор расширений.

## Подтверждённые проблемы
- LevelManager использовал UnityEditor без условной компиляции: ошибка при сборке Player.
- Singleton присваивался в конструкторе MonoBehaviour.
- CurrentLevel setter вызывал GetInt вместо записи; индексы смешивались с номером уровня.
- Пустой список и единственный случайный уровень приводили к недопустимым индексам/делению на ноль.
- Удаление детей использовало DestroyImmediate в runtime.
- Inspector удалял все PlayerPrefs и посторонние файлы сохранений.
- Выданные surface shaders содержат DummyShaderTextExporter и не совместимы с URP; восстановление внешнего вида нужно в этапе 1.
- Игровая сцена, готовые персонажи и анимационные контроллеры ещё не собраны. Это исходная незавершённость, а не готовый первый уровень.

## Выполненные исправления
- Инициализация singleton перенесена в Awake, ссылка очищается при уничтожении менеджера.
- Разделены порядковый номер прохождения и индекс префаба; исправлены сохранение прогресса, повтор одного уровня и нормализация индексов.
- Добавлены проверки пустого списка и отсутствующего префаба; неудачный выбор сохраняет текущий уровень и прогресс.
- Старый уровень сразу отключается и уничтожается отложенно в Play Mode.
- Сброс очищает только четыре ключа Level Manager; удаление посторонних сохранений исключено.
- Runtime и Editor отделены сборками, добавлены девять PlayMode-тестов и Editor-инструмент диагностики.
- Подготовлены AGENTS.md, два локальных скилла, две конфигурации ролей ревью, правила совместимости Cursor, настройки текста и Git.

## Проверки
Проверено в отдельной копии Assets, Packages и ProjectSettings, с чистым импортом Unity 6000.3.22f1.
- Компиляция Editor: успешно.
- PlayMode: **9 из 9 тестов пройдены**, ошибок тестов нет.
- Отсутствующие MonoBehaviour в сценах сборки: **0**.
- Материалы без доступного шейдера: **42**. Они остаются исходными ресурсами и требуют восстановления в этапе 1; проверка проекта не означает готовность этих материалов.
- FBX player: **85 Transform, 8 SkinnedMeshRenderer** — скелет и меши есть.
- FBX photographer: **81 Transform, 2 SkinnedMeshRenderer**.
- Анимационные клипы в шести FBX: **0**. Нужно создавать/подбирать и ретаргетировать анимации; это существенная работа, а не только настройка Animator.
- Все 7 поставленных шейдеров — surface shaders; их нельзя напрямую использовать для целевого вида в URP.
- Скиллы прошли quick_validate; TOML-конфигурации агентов разбираются корректно. Оба скилла обнаружены Codex; отдельный запуск ролей ревью не выполнялся.
- Проверочная **Windows x64 Development-сборка исходной SampleScene успешна: 0 ошибок, 0 предупреждений BuildReport**, код выхода Unity 0. Она не проверяет внешний вид всех неиспользованных материалов.
- Первый запуск сборки завершился OutOfMemoryException в Burst при компиляции URP. Повтор успешно завершён с `-job-worker-count 2 -background-job-worker-count 2` и ограничением процесса двумя логическими CPU (ProcessorAffinity=3). Burst и оптимизации не отключались, пакеты не обновлялись. При повторении нехватки памяти сократить параллельность сборки или освободить память.
- Проверенные C# и asmdef побайтово совпадают с исходным проектом. Временная копия и логи остаются локально в Temp/ValidationProject.
- Геймплей и визуальное соответствие ещё не проверяются: игровая сцена не реализована.
