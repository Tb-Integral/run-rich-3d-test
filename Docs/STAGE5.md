# Этап 5 — маршрут, ворота и флаги

Статус: подготовлен к ручной проверке. Коммит — после подтверждения пользователя.

## Проверка в Unity

1. Выйти из Play Mode и переоткрыть `Assets/_Project/Scenes/Gameplay.unity`. Дождаться импорта; Game View 880×1920 либо 440×960.
2. Начать забег. Стартовая походка заметно грустная (примерно 47% Sad Walk / 53% Walking); после рестарта возвращается та же походка. На первом участке деньги стоят справа, затем поперёк дороги и слева. Бутылки уменьшают счёт, их можно обходить. Непрерывное управление и поворот модели сохранены.
3. Пройти первый поворот направо. На жёлтой зоне флаги поднимутся. От зоны не меняются счёт, одежда и скорость.
4. У ворот справа выбрать «ШКОЛА»: +20, при пересечении порога — улучшение одежды с вращением. Затем проверить через перезапуск левую «ВЕЧЕРИНКУ»: −20 и ухудшение без вращения. В одни ворота нельзя войти дважды или получить оба результата.
5. После школы маршрут поворачивает налево; вторая жёлтая зона снова поднимает флаги. Первый ряд бутылок обходится слева, следующие — справа. Дальше стоят деньги.
6. После третьего поворота направо пройти третью зону флагов и последний блок денег. В конце персонаж временно останавливается и танцует, как на прошлом этапе. Финишные множители и экраны результатов будут добавлены этапом 6.
7. Перезапустить после ворот или флагов: все пикапы восстановлены, обе стороны ворот снова доступны, флаги снова опущены, счёт 40 и стартовая одежда. На отрицательном результате продолжает работать поражение со Stomping.

Для прохода, похожего на видео: собрать первые деньги справа, затем слева; одну бутылку перед первым поворотом взять по центру. Перед школой держаться справа; после второго поворота обойти первый ряд бутылок слева и перейти вправо. По этому контрольному пути счёт у финишного якоря — 96. Другой путь закономерно даёт другой результат.

## Редактирование

- `Level01.prefab` → TrackPath: четыре прямых и три дуги; подготовленный меш сохранён в `FirstLevelTrack.asset`. Геометрия не генерируется при запуске игры.
- Pickups содержит купюры и бутылки; Choices and Flags — парные ворота и три жёлтые области. Их положение задаётся полями Distance и Lateral Offset, Inspector размещает объект по трассе.
- `SchoolPartyGate.prefab` → ChoiceGate: School Reward = 20, Party Penalty = 20. Сторона выбирается один раз по позиции пересечения; точный центр относится к школе.
- `FlagZone.prefab` → FlagZone: Raise Duration = 0.35. Эти области не дают награду и не меняют скорость.
- Finish Anchor отмечает конец основной части. Под ним добавлен небольшой запас пола для остановки; будущая финишная последовательность будет продолжена от этой точки.
- `Tools → Run Rich → Prepare First Level` — явная пересборка исходной расстановки, заменяющая ручные изменения Level01. Для обычного запуска использовать её не нужно.

## Границы достоверности

Точные координаты предметов, радиусы поворотов, длительность подъёма флагов и штраф вечеринки не восстановлены из исходного кода. Принятые значения и наблюдения разделены в REFERENCE.md. Полного совпадения 1:1 пока не заявляется; детальная сверка эффектов и UI остаётся этапом 7. Touch на устройстве не проверен.
