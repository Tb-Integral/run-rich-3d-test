# Этап 3 — старт и цикл забега

Статус: завершён и принят пользователем; получено разрешение на коммит и переход к этапу 4.

## Проверка

1. Выйти из Play Mode, заново открыть Gameplay и дождаться компиляции. Портретный Game View 440×960 или 880×1920; также проверить 9:16.
2. Нажать Play. Персонаж ожидает в Look Around, дорожка неподвижна. Вверху отображаются номер уровня и счёт 40. Внизу — подсказка, стрелки и движущаяся рука.
3. Нажать и провести мышью по Game View. Подсказка скрывается, начинается ходьба. Принятые на этапе 2 перемещение и повороты модельки сохранены.
4. Нажать кнопку с круговой стрелкой справа сверху. Уровень загружается заново, персонаж возвращается на старт в исходной одежде, счёт снова 40, подсказка возвращается. Нажатие кнопки не должно одновременно запускать забег.
5. До конца тестовой дорожки дойти автоматически. Персонаж останавливается, через 0.8 с начинает танец. Движения мыши больше не перемещают его. Кнопка перезапуска возвращает в ожидание.
6. Для проверки поражения: выбрать Run Session в Hierarchy и во время ходьбы нажать «Поражение» в Inspector. Проигрывается Stomping, движение блокируется. Перезапуск снова возвращает в ожидание.
7. Во время ходьбы можно проверить «Начать завершение» в Inspector Run Session. Повторные команды завершения не меняют уже завершённый исход.

## Объекты и настройки

- Run Session хранит Ready → Running → Finishing → Won либо Running → Lost. Из любого состояния доступен перезапуск в Ready.
- Levels содержит выданный Level Manager и RunLevelSource. Дорожка хранится в `Assets/_Project/Prefabs/Level01.prefab`; список — `Assets/_Project/Settings/PlayableLevels.asset`. При загрузке создаётся экземпляр готового префаба, геометрия во время игры не генерируется.
- Gameplay UI — редактируемый Canvas со скейлером и учётом безопасной области экрана. Использованы выданные hand, arrow_left_right, restart и Inter-SemiBold.
- Run Session → Initial Score = 40; Finish Delay = 0.8. UI показывает номер из Level Manager; перезапуск не увеличивает номер. При старте учитывается одна попытка.
- Подготовительный Editor-инструмент Prepare Run Session Stage нужен только для явного восстановления этапа; при обычном запуске использовать его не нужно.

## Границы этого этапа

- Счёт пока стартовый: пикапы и шкала подключаются на этапе 4.
- Конец тестовой дорожки временно завершает забег через задержку. Полноценная финишная последовательность, экраны результатов и Next относятся к этапу 6.
- Принудительное поражение и завершение доступны только через Inspector Editor. Игровых отладочных кнопок нет.
- Метапрогресс, магазин, реклама и верхняя панель островов из видео не входят в задачу. Кнопка перезапуска добавлена для проверки текущего цикла.
- Проверка касаний на телефоне не выполнена; для текущей ручной приёмки используется мышь.
