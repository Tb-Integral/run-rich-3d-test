# Этап 6 — финиш и следующий уровень

## Проверка в Unity
1. Открыть `Assets/_Project/Scenes/Gameplay.unity`, портретный Game View 880×1920, нажать Play.
2. Пройти основной маршрут. После шахматной линии продолжается забег: можно обходить алкоголь и собирать деньги между воротами x2–x5.
3. При достаточном счёте промежуточные ворота x2/x3/x4 открываются (пороги 20/65/105). У недоступных ворот персонаж останавливается и танцует. Последние золотые ворота x5 всегда остаются закрытыми: даже при счёте 150 персонаж останавливается перед ними. При счёте от 140 результат получает x5; прохода за ворота нет.
4. Для прохода как в видео прийти к шахматной линии со счётом 96 и собрать семь купюр слева в финишном коридоре. Итог — 110, множитель x4, результат 440. Точные пороги — принятая гипотеза, поскольку в видео они не подписаны.
5. Нажать «Далее»: номер увеличился на один, персонаж снова ждёт первого жеста, деньги/бутылки/флаги/ворота восстановились, счёт 40 и грустная походка вернулись. Удержание кнопки или быстрый двойной клик не должны пропускать уровень.
6. Начать второй забег. Для задания используется тот же маршрут. Остановить Play и снова запустить: номер уровня должен сохраниться.
7. Проверить поражение: опустить счёт ниже нуля. Персонаж остановился и играет Stomping, через 0.8 с появилась «Ещё раз». Нажать: восстановлен тот же номер уровня без старых эффектов/множителя. Точный ноль сам по себе не является поражением.

8. Проверить максимальный счёт: перед золотыми воротами остановка и танец, сами ворота закрыты. За ними продолжается дорожка с кучей денег; это декорация без подбора. Пройденные ворота больше не исчезают.

## Быстрая проверка отдельных исходов
- В Play Mode `Runner → Player Wealth` позволяет изменить счёт; `Run Session` содержит Editor-кнопку «Начать завершение» и «Поражение». Эти действия предназначены только для проверки; полное прохождение всё равно нужно проверить отдельно.
- Стартовые настройки походки остались в `Assets/_Project/Settings/WealthSettings.asset` (Happy Score = 150).
- Ворота и их пороги находятся в `Assets/_Project/Prefabs/Level01.prefab → Finish Course → FinishGateX2…X5 → Finish Gate`. Настройки экземпляра имеют приоритет над префабом.
- `Tools → Run Rich → Prepare Finish Stage` явно пересобирает только финиш, геометрию последней прямой и экран результата. При обычном запуске объекты не генерируются.

## Объём
Добавлены шахматная линия, четыре вида ворот, дополнительные пикапы, ковры/скамейки/мусор, фотограф с Arm Stretching, результат победы/поражения, повтор и переход через исходный Level Manager. Рекламная рулетка и отдельный кошелёк отсутствуют; кнопка «Далее» показывает результат забега. Внешний вид поражения принят для задания: в ролике его нет. Проверка touch на устройстве не выполнена.

Этап принят пользователем после доработки финальных ворот и камеры. Разрешены коммит и переход к полишингу.
