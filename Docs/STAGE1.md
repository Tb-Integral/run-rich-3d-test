# Этап 1 — повторная проверка после замечаний

Этап принят пользователем 16.09.2026 после исправления импорта скрипта и обратного сгиба коленей. Получено разрешение на коммит и публикацию изменений.

## Проверка в Unity

1. Дождаться импорта, открыть `Assets/_Project/Scenes/Gameplay.unity`. Если сцена оставалась открытой со старой версией, переоткрыть её с диска.
2. Выбрать Game View **880 × 1920** и нажать Play. Персонаж ожидает: проигрывается скачанная **Look Around**.
3. Выбрать **Runner** в Hierarchy. Внизу компонента **Player Presentation** доступны кнопки проверки только для Editor.
4. Нажать **Ходьба**. Ползунок **Счастье**: 0 — Sad Walk, 0.5 — Walking, 1 — Happy Walk. Между значениями походки смешиваются; после резкого изменения ползунка переход смягчается.
5. Нажать **Одежда лучше**: включается следующий костюм, персонаж быстро поворачивается на 360° с разведёнными руками и согнутой ногой. После поворота возвращается к походке. Корневой Runner не меняет позицию и направление.
6. Нажать **Одежда хуже** и уменьшить счастье: одежда меняется без поворота, походка становится грустнее. Параметры разделены для проверки; игровые пикапы и ворота свяжут их на следующих этапах.
7. Проверить **Победа — танец**, затем **Сбросить проверку**, затем **Поражение — Stomping**. После поражения кнопка ходьбы не должна перебивать финальную анимацию. Для нового теста нажать сброс.
8. Посмотреть тень у ног и вдали: контур должен быть мягким, без прежних крупных ступеней. Остановить Play и проверить Console.

После исправления коленей: остановить Play, выполнить Assets → Refresh и дождаться импорта анимаций. Повторить ходьбу со счастьем 0, 0.25, 0.5, 0.75 и 1; осмотреть сбоку оба колена на протяжении полного цикла. Они должны сгибаться вперёд, без прежнего обратного излома. Настройки переноса позы исправлены, исходные скачанные клипы сохранены.

## Использование исходных моделей

В сцене `Runner/VisualPivot/player` — связанный экземпляр `Assets/Visual/Mesh/LowPoly/player.fbx`. Скелет и меши не копируются в отдельный распакованный префаб. Runner служит корнем будущего движения, VisualPivot поворачивает только видимую модель.

Старый Runner.prefab, временные CasualIdle/CasualWalk и их генератор удалены. Скачанные клипы используются прямо из FBX в `Assets/Animations`; для ретаргетинга настроены Humanoid Avatar.

Для `photographer.fbx` настроен Humanoid и подготовлен `Assets/_Project/Animations/Photographer.controller` с Arm Stretching. Фотограф будет размещён при сборке финиша. При желании клип можно проверить отдельно: перетащить исходный photographer.fbx в сцену и назначить этот контроллер его Animator, не сохранять тестовые изменения сцены.

## Ограничения

Самостоятельно создан только UpgradePose — поза для быстрого поворота по скриншоту. Поворот VisualPivot выполняется компонентом представления, не затрагивая корень движения. Ручная оценка темпа и позы ещё нужна.

Движение по трассе, управление, игровой UI и предметы остаются следующими этапами. Ползунок и кнопки находятся в Inspector, не входят в игровой интерфейс и не подменяют игровой цикл.

`Tools → Run Rich → Rebuild Visual Foundation` явно пересоздаёт основу сцены и контроллеры; для обычной проверки эта команда не нужна. Коммит — после подтверждения пользователя.
