# Run Rich 3D — тестовое задание

Unity-проект для воспроизведения первого уровня Run Rich 3D по выданному видео. Принят этап 1: визуальная сцена и анимации. Принят этап 2: непрерывное управление мышью/touch, движение по дорожке с двумя поворотами и камера. Принят этап 3: стартовый UI и цикл забега с перезапуском. Принят этап 4: деньги и алкоголь, шкала, смена одежды и походки, эффекты подбора. Принят этап 5: основной маршрут первого уровня, ворота и области с флагами. Принят этап 6: финиш x2–x5, фотограф, экраны результата, повтор и следующий уровень; состояние проверок указано в отчёте проекта.

## Открытие
1. Установить Unity **6000.3.22f1** через Unity Hub.
2. Клонировать репозиторий, добавить корневую папку проекта в Hub, дождаться импорта пакетов и ассетов.
3. Открыть `Assets/_Project/Scenes/Gameplay.unity`, выбрать портретный Game View **880 × 1920** и нажать Play.
4. Персонаж ждёт первого нажатия в Game View. Зажать левую кнопку мыши и перемещать её влево/вправо. Перезапуск — кнопка с круговой стрелкой справа сверху. Проверка Android на устройстве пока не выполнена.
5. [Инструкция ручной проверки этапа 6](Docs/STAGE6.md); [маршрут первого уровня](Docs/STAGE5.md); [шкала и пикапы](Docs/STAGE4.md); [старт и перезапуск](Docs/STAGE3.md); [управление](Docs/STAGE2.md).

Ассеты и исходный Level Manager предоставлены вместе с заданием. GUID используемых исходных ресурсов сохранены; удалённые сломанные материалы описаны в отчёте. Собственный код размещается в `Assets/_Project`; существующий менеджер — в `Assets/Level Manager`. Общая открытая лицензия на сторонние ассеты не назначается.

Магазин, реклама и мета не входят в объём. Следующий уровень может повторять первый. Ссылка на итоговое минутное видео появится после завершения реализации и публикации ролика.

## Проверки
- `Tools → Run Rich → Validate Project`: инвентаризация моделей, клипов, материалов и компонентов сцен. Результат в `Logs/project-validation.json`.
- `Window → General → Test Runner → PlayMode`: запустить `RunRich.PlayModeTests` для проверки Level Manager, анимации, ввода, движения, цикла забега и пикапов в Gameplay. Тесты менеджера временно меняют только ключи его прогресса и восстанавливают прежние значения.
- `RunRich.Editor.ProjectValidation.ValidateAndBuild`: метод для batch-проверки и сборки включённых сцен под Windows. Проверочная сборка не является готовой игрой.
- Папки `Logs`, `Temp`, `Library` и `Builds` исключены из Git. Итоги проверок описаны в `Docs/PROJECT_HEALTH.md`.
