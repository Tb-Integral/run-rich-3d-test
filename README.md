# Run Rich 3D — тестовое задание

Unity-проект для воспроизведения первого уровня Run Rich 3D по выданному видео. Текущий статус: подготовлена техническая основа; геймплей ещё не реализован. Пройдены 9 PlayMode-тестов и проверочная Windows-сборка исходной сцены.

## Открытие
1. Установить Unity **6000.3.22f1** через Unity Hub.
2. Клонировать репозиторий, добавить корневую папку проекта в Hub, дождаться импорта пакетов и ассетов.
3. Пока доступна только `Assets/Scenes/SampleScene.unity` — исходная пустая сцена. Gameplay будет добавлена в этапе 1.
4. Проверять будущий геймплей в портретном Game View, мышью. Проверка Android на устройстве пока не выполнена.

Ассеты и исходный Level Manager предоставлены вместе с заданием. Их исходные наименования и GUID сохранены. Собственный код размещается в `Assets/_Project`; существующий менеджер — в `Assets/Level Manager`. Общая открытая лицензия на сторонние ассеты не назначается.

Магазин, реклама и мета не входят в объём. Следующий уровень может повторять первый. Ссылка на итоговое минутное видео появится после завершения реализации и публикации ролика.

## Проверки
- `Tools → Run Rich → Validate Project`: инвентаризация моделей, клипов, материалов и компонентов сцен. Результат в `Logs/project-validation.json`.
- `Window → General → Test Runner → PlayMode`: запустить `RunRich.PlayModeTests` для проверки Level Manager. Тесты временно меняют только ключи его прогресса и восстанавливают прежние значения.
- `RunRich.Editor.ProjectValidation.ValidateAndBuild`: метод для batch-проверки и сборки исходной сцены под Windows. Проверочная сборка не является готовой игрой.
- Папки `Logs`, `Temp`, `Library` и `Builds` исключены из Git. Итоги проверок описаны в `Docs/PROJECT_HEALTH.md`.
