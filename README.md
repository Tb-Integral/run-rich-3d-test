# Run Rich 3D — тестовое задание

Реализация первого уровня раннера по видео-референсу: сбор денег и алкоголя, изменение одежды и походки, ворота, зоны с флагами, победа и поражение. Добавлены UI, анимации, эффекты и звук. После победы следующий номер уровня использует тот же маршрут.

## Запуск

1. Открыть проект в **Unity 6000.3.22f1** и дождаться импорта зависимостей.
2. Открыть сцену `Assets/_Project/Scenes/Gameplay.unity`.
3. Выбрать в Game View разрешение **880 × 1920**, включить звук и нажать **Play**.

## Управление

- Нажатие в Game View начинает забег.
- Удержание левой кнопки мыши и перемещение влево/вправо управляют персонажем. Движение вперёд автоматическое.
- Круговая стрелка перезапускает забег; «Далее» открывает следующий уровень, «Ещё раз» повторяет попытку после поражения.

Основная проверка выполнена в Unity Editor с мышью. Touch-ввод реализован, проверка на устройстве не проводилась.

## Код и настройки

- `Assets/_Project/Runtime` — ввод, движение, состояние забега, экономика и представление.
- `Assets/_Project/Settings` — настройки движения, шкалы и звука.
- `Assets/_Project/Prefabs/Level01.prefab` — маршрут и объекты уровня.
- `Assets/Level Manager` — предоставленный менеджер уровней.

## Тесты

**Window → General → Test Runner → PlayMode → RunRich.PlayModeTests**.

Пройдены 42 теста: проверены управление, пороги шкалы, однократные взаимодействия, финиш, перезапуск, переход между уровнями и сброс эффектов.
